# Publicación documental

GitHub Pages presenta el README, los seis proyectos UNE, anexos y evidencias visuales de OpenMetadata sin mantener un clúster Kubernetes público.

El workflow `.github/workflows/pages.yml` construye el repositorio con Jekyll y publica el resultado en `https://alonsomarcosm.github.io/TrabajoGobiernoCalidadDatos/`.

La web es evidencia documental. La reproducción operativa de OpenMetadata sigue los scripts del repositorio y requiere un entorno local controlado.
